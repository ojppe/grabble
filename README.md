# [Grabble](https://grabble.org)
Open Scrabble server based on [lila](https://github.com/lichess-org/lila)

Features:
- Tournaments
- Multiplayer 2-4
- Customizable board layout
- Different time controls
- Game archive
- Statistics
- Rankings
- Analysis
- Puzzles
- Trainer
